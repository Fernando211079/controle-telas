ARQUIVOS PARA SUBSTITUIR (já existem no repo):

OPÇÃO A — pelo site do GitHub (sem instalar nada):
  1. Abra https://github.com/Fernando211079/controle-telas
  2. Para substituir: clique no arquivo → ícone de caneta (Edit) → apague tudo
     e cole o conteúdo do arquivo correspondente deste pacote → Commit changes.
  3. Para adicionar novos: Add file → Upload files → arraste os arquivos
     (ou Create new file e cole o conteúdo; nos ícones use Upload).

OPÇÃO B — pelo PC (Git instalado):
  1. Extraia este ZIP sobre a pasta do projeto (substituindo os 4 arquivos).
  2. Abra o terminal na pasta e rode:
       git add -A
       git commit -m "v1.2: ano dinâmico, correções de salvamento, PWA instalável"
       git push

DEPOIS: publique pelo botão Publish do Verdent (o build copia o manifest e o
sw.js para o dist automaticamente).

PWA (app instalável no celular e no PC)
=======================================
- Android/Chrome: abra a URL publicada → menu ⋮ → "Instalar app".
- iPhone/Safari: Compartilhar → "Adicionar à Tela de Início".
- PC: ícone de instalação na barra de endereço do Chrome/Edge.
- O app abre em tela cheia, com ícone próprio, e funciona offline.
- As chamadas ao Supabase NUNCA são cacheadas (sempre dados frescos).
